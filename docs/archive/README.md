# 归档文档

本目录存放已停止维护的文档，仅供历史参考和追溯。当前有效的架构、接口契约和开发约定见[开发文档索引](../README.md)。

## 归档范围

| 情况 | 处理 |
|---|---|
| 模块开发手册：模块或阶段交付完成 | 整篇归档，不再随实现更新 |
| 被替代的设计、方案或接口草案 | 归档旧版本，现行版本保留在 `docs/` 下 |
| 已废弃的能力或接口说明 | 相关实现下线后归档 |
| 长期失去维护价值的过程性材料 | 按需归档，不在此新增过程记录 |

已实现的架构、接口契约、开发约定、部署要求和提交规范长期维护，不归档。规划中的能力在落地后按实际情况归档，或转入现行接口文档。

## 归档方式

1. 将文件移入本目录并保留原文件名；重名时在文件名后追加归档年月，例如 `SERVICE_BOOKING_DESIGN-2026-09.md`。
2. 在被归档文件的状态说明中标注“状态：已归档（YYYY-MM-DD）”，并写明归档原因与替代文档。
3. 在下方清单登记，便于检索和追溯。
4. 同步更新[开发文档索引](../README.md)，从现行文档列表移除该文档或标注为已归档。

本目录不新增独立编写的内容，只接收从 `docs/` 移入的文档和本说明文件。

归档文档不代表当前实现和接口契约。引用其中的设计、字段或路径时，必须以源码、Flyway 迁移和现行文档为准；归档内容与现行文档冲突时以现行文档为准。归档前需移除凭据、密钥和真实个人信息。
