## 实现范围

当前包含基础认证、角色和社区校验、统一响应、数据库迁移、老人档案后端与管理端页面、管理后台框架及移动端基础页面。健康档案、家属授权、服务目录、履约、求助投递和微信认证尚未实现。

已落地数据库表为`community`、`user_account`、`elder_profile`和`elder_profile_event`。其他规划能力落地时应同步更新接口文档和对应测试。

## 维护约定

- 工程行为以源码、迁移和锁文件为准；契约变更与实现同时提交。
- 规划能力标注状态，不混入已实现接口列表。
- 版本升级更新依赖依据；不在文档中存放凭据或真实个人信息。
- 模块交付完成，或文档被替代、废弃后，移入[归档目录](archive/README.md)并在其中登记；归档文档不作为现行契约。
